# ShortLearn — Stitch assets

Nguồn giao diện hiện tại cho Stitch: ảnh chụp app Android và SVG editable.

## Assets

- `screens/current-development-client.png`: Ảnh chụp emulator hiện tại.
- `screens/01_shorts_player.png` … `06_tiktok_player.png`: Các màn hình ShortLearn đã xuất.
- `svg/`: Bản SVG vector, có thể import trực tiếp vào [Stitch](https://stitch.withgoogle.com/).

## Cách dùng Stitch

1. Mở https://stitch.withgoogle.com/.
2. Tạo project ShortLearn.
3. Kéo thả ảnh tại `screens/` làm visual reference.
4. Kéo thả SVG cần chỉnh sửa từ `svg/`.
5. Giữ dark design system: `#090D16`, `#0F172A`, `#38BDF8`, `#F59E0B`, `#A855F7`.

Nguồn runtime: React Native app tại `shortlearn-app/`. Assets mô tả UI, không thay thế mã nguồn.
