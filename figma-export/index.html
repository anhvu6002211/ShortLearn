1
Cách 1: Copy SVG & Paste (Ctrl + V)
Bấm nút "📋 Copy SVG cho Figma" bên dưới. Mở dự án Figma và nhấn Ctrl + V. Mọi layer chữ, icon vector, frame autolayout sẽ được tạo ngay lập tức.
2
Cách 2: Kéo thả file SVG / PNG
Thư mục figma-export/svg/ chứa 7 file .svg vector tinh khiết. Bạn có thể kéo thả trực tiếp từng file vào canvas Figma.
3
Cách 3: Ảnh thực tế từ Android Studio
Thư mục figma-export/screens/ chứa các ảnh PNG 1080x2400 trích xuất sạch sẽ từ ADB để làm mockup so sánh hoặc portfolio.
